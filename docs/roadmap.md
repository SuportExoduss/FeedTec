# Roadmap FeedTec

## F1 — Base
Estrutura Expo + android/, login Google, técnicos (adicionar, editar, remover), salvamento no Drive, perfil.

## F2 — Feedback escrito
Escolher tom (A melhorar / Neutro / Positivo) → texto bruto → Gemini (chave do gestor no Perfil) devolve feedback pronto, editável.
Histórico por técnico, agrupado por dia.

## F3 — Feedback gravado
Gravar conversa (expo-audio) → Gemini → transcrição com separação de vozes →
app pergunta quem é cada voz (você / técnico) → feedback no tom escolhido + aba "Conversa" em formato de chat.
Áudio salvo na pasta FeedTec do Drive.

## F4 — Menu lateral (☰)
Histórico geral: abrir conversa, ouvir gravação, ver transcrição em chat e feedbacks feitos.

## F5 — Tarefas e reuniões
Agenda simples (tarefa, dia, lembrete, descrição) com notificação local; reuniões semanais recorrentes.

## F6 — Android e publicação
Ajustes nativos, ícone/splash, web no Firebase Hosting.
